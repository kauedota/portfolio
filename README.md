# 👨‍💻 Portfólio Pessoal - Kauê Dota

Portfólio desenvolvido para apresentar meus projetos e habilidades como Desenvolvedor Full Stack. O projeto é dinâmico e inteligente, consumindo dados diretamente da API do GitHub para manter a lista de repositórios e informações de perfil sempre atualizadas[cite: 4].

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

*   **HTML5:** Estruturação semântica.
*   **CSS3:** Estilização com variáveis (Custom Properties), animações, Flexbox, Grid e layout totalmente responsivo com otimização para dispositivos móveis[cite: 3].
*   **JavaScript (Vanilla):** Consumo de API REST (Async/Await), manipulação dinâmica do DOM e validação de formulário[cite: 4].
*   **Swiper.js:** Biblioteca moderna utilizada para a criação do carrossel interativo na seção de projetos[cite: 1, 4].
*   **API do GitHub:** Integração para busca automática de repositórios, descrição, linguagens e geração de links de deploy[cite: 4].
*   **FormSubmit:** Serviço integrado para envio de e-mails diretamente pelo formulário estático[cite: 1].

## ✨ Funcionalidades

*   **Sincronização Automática com GitHub:** A seção "Sobre mim" e o carrossel "Meus Projetos" são alimentados automaticamente pela API do GitHub[cite: 4]. 
*   **Smart Deploy Links:** Os botões de "Deploy" são gerados e exibidos dinamicamente no card do projeto caso o repositório possua o GitHub Pages ativo ou um link configurado[cite: 4].
*   **Design Responsivo:** Interface fluida e adaptável para qualquer tamanho de tela, com ajustes finos e dedicados para celulares menores[cite: 3].
*   **Formulário de Contato Seguro:** Validação de campos obrigatórios via JavaScript (nome, e-mail no formato correto, assunto e mensagem) e redirecionamento para uma página de sucesso personalizada[cite: 2, 4].
*   **Links de Contato Rápidos:** Redirecionamento direto para LinkedIn, GitHub, Instagram e WhatsApp[cite: 1].
